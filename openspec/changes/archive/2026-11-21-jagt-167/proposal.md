## Why

The press-time checks of `ship`, `deploy` and `revert` (git trust, a fresh merged read, a stop) lived beside the chart as interceptors, so `TaskOffers` was not the only legal-move set.

## What Changes

- The task chart offers `ship`, `deploy` and `revert` only where what the press reads says go: git obeys what was trusted, no request is found merged, no stop holds against a non-human origin.
- Those reads run on a press of the gated verb only, never in the projection.
- A state git cannot be read from refuses with `git state of <task> could not be read: <why>`.
