## Why

A hook's sign took the session start the task stood at on arrival, so a sign from a session that had since restarted moved the new one.

## What Changes

- Each session's process starts with the session start it began on; its hooks post it in a header.
- The sign lands on that start; a hook naming none lands on the start of its arrival.

## Capabilities

### Modified Capabilities

- `protocol`: a hook's post names the session start it was sent from.
