## Why

An item labelled for two projects was placed in one: the router, asked to pick, dropped the other with no log and no question.
A label is the human's choice and a model never narrows it.

## What Changes

- Every project an item's labels name receives the item; the router runs only where no label matched.
- A plan for a task with several repositories names each one as changed or unaffected, so a repository leaves the task only by an approved plan line.

## Capabilities

### Modified Capabilities

- `board-workspace`: placement attaches every labelled project.
- `acceptance-probes`: the plan carries a `## Repositories` section for a multi-repository task.
