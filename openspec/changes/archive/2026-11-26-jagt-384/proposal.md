## Why

No rule said when a fixed bug adds a spec scenario or a chart state, nor what a fix's postmortem holds.
Twelve of the last twenty Defect-family commits carried no openspec file.

## What Changes

- A fixed bug names its case: new, existing or none.
- A fix adds a chart region only for a condition across moves with its own exit; a wrong edge is one edge row.
- A Defect-family commit carries `Case`, `Written`, `Uncaught` and `Unseen` trailers.
- `FixedBugCaseFitness` fails one without `Case`, or touching main code with neither an openspec file nor `Case: existing`.
