## Why

A session could set config or a hook that makes git run a program, and `deploy`, `revert`, `ship` or the Master's read
then ran it with the human's credentials. jagt kept no record to notice the change.

## What Changes

- Each task records what its git obeys as its worktrees are cut.
- `ship`, `deploy`, `revert` and a Master read refuse while that differs, naming key and file, and park the task.
- `trust`, a human-only verb, adopts what changed.

## Capabilities

### New Capabilities

- `git-trust`: git with the human's credentials runs only config and hooks a human trusted.
