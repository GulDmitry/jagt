## Why

An assistant whose MCP server needs a login only logs a fix; the human leaves the board for a terminal.

## What Changes

- A probe finding an MCP server down is a lost reach on the board's head; its mark opens `claude` as the login window,
  and the human types `/mcp` through `say`.
- While the mark stands a job asks again each minute; every server connected ends it.

## Impact

- `board`: one scenario under the lost-reach requirement. Out of scope: a browser jagt drives.
