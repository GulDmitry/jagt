## Why

A review read called `mr_discussions`, which names no read verb, so the read gate refused it; the read was then asked
three times more, each paid, and the round ended unreadable.

## What Changes

- A server's reads include its `*discussions*` and `*notes*` tools; a write verb still refuses them.
- A read the gate refused a tool is not asked again.
