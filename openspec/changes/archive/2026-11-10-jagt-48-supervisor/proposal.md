## Why
A rebuilt jar and a refused start need the machine today; jagt down is one of two cases outside the board.
## What changes
- A `supervisor` seam keeps the staged jar running and restarts it; `supervise` installs it, `restart` restarts it, both board verbs.
- A start refused for a fixable cause serves a failure page listing every problem, with an editor for `jagt.yml` that saves and starts again.
- New capability `supervisor`.
