## Why

A one-repository card named its project in plain text beside a `request` chip, while a card spanning repositories
opened each request from its project's name: two ways to read one fact on one board.

## What Changes

- Where the board names projects, a one-repository card's request opens from its project's name, which keeps the age; the
  word `request` goes. A board of one project keeps the `request` chip.

## Capabilities

### Modified Capabilities

- `board`: the project's name opens its request wherever the board names projects.
