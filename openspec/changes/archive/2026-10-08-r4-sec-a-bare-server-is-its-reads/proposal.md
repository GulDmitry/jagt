## Why

A bare `mcp__<server>` in `assistant.allowedTools`, the form `jagt.yml.dist` taught, granted every tool of that
server to a headless read and the Master's review, `save_note` included.

## What Changes

- A bare server stands for its read verbs' globs; only a full tool name or glob widens past them.
- `ReadGate` matches a name exactly or as a glob, never as a server prefix.

## Capabilities

### Modified Capabilities

- `protocol`: a bare server in `allowed-tools` is its reads.
