## Why

A model id merely containing a known family name was priced at that family's rate, so a total read complete when it was not.

## What Changes

- A model is priced only by its exact id, a dated variant (`-YYYYMMDD`) at its undated id's price; any other id is unpriced.

## Capabilities

### Modified Capabilities

- `unpriced-cost`: an id merely containing a known name is unpriced.
