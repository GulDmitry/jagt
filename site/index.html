Features

Eight architecture principles, each with the file that holds it: Architecture principles.

1

Fitness functions guard the architecture

What it is
every architecture rule is a fitness function declared in fitness.yml. Each one reports its number against its threshold, over all code, tests included. The core imports no Spring, and arrows point inward only.
Why it matters
a rule that a build checks does not erode when the code grows.
Held by
fitness, fitness.yml, 0162
2

A statechart decides every status

What it is
a capability does its work and reports an outcome. A Harel statechart with nested and parallel states, history and choices says which status that outcome leads to.
Why it matters
no code path can move a task to a status the chart does not allow.
Held by
statechart, task-flow, 0110
3

Roles are isolated folders

What it is
a role is one folder with its brief, its cases and a design file. jagt installs a role. It does not code one.
Why it matters
a new role changes no existing role, and one role can break only itself.
Held by
roles/session/design.md, roles/master/design.md, ARCHITECTURE.md
4

Pluggable agents and models

What it is
a session runs on Claude Code, Codex or OpenCode, on the model you name. A local model can answer the reads that need no tool. Each is a key in jagt.yml, like every third party: one port, one driver for each vendor.
Why it matters
jagt guesses no vendor from a name or a URL, and swapping an agent or a model is a config change.
Held by
agent-seams, 0130, seams
5

Use cases first

What it is
every behaviour is a WHEN and THEN scenario in a spec, and a test pins it.
Why it matters
a change shows its effect as a scenario before it shows as code.
Held by
spec-changes, testing
6

A protocol validated at every step

What it is
at each step a session reports a typed record. jagt checks it against a schema at the door and returns every violation at once.
Why it matters
jagt never parses prose, so a changed sentence cannot change a decision.
Held by
protocol, 0077

Install

On a desktop

macOS, Linux and WSL:

$ curl -fsSL https://github.com/GulDmitry/jagt/releases/latest/download/install.sh | sh

Windows, in PowerShell:

PS> irm https://github.com/GulDmitry/jagt/releases/latest/download/install.ps1 | iex

Both install for your user only, without admin rights, and check the download against its published checksum.

Run jagt, then open the board at http://localhost:8290.

On a server

Name your project in jagt.server.yml.dist first: the image bakes it in as the starting jagt.yml.

$ docker compose up -d --build

One container with the board behind a password login: docs/server.md.
