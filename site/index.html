What jagt does

Several tickets at once

A reviewer before you read

Done means checked

How it works

jagt hands a ticket to an autonomous AI coding agent in its own isolated Git worktree, so two agents cannot see or break each other's work. You drive all of them from one board in your browser.

The board

A row shows status, age and checks; pick one and its detail opens beside the list.

Sessions

Sessions live in tmux and the state is one JSON file, so restarting the backend loses nothing

Git worktree

Nothing is written into your project's tracked files

Install

Tools: Technologies

  1. check MCP access 
    $ cd "$TMPDIR" && claude "Name your MCP tools for <your tracker> and <your code host>, or say NONE." -p
  2. clone, and name one repository 
    $ git clone https://github.com/GulDmitry/jagt.git && cd jagt
$ cp jagt.yml.dist jagt.yml
  3. build, and run 
    $ cd orchestrator-backend
$ ./gradlew build stageJar
$ java -jar build/libs/jagt-run.jar
  4. open the board http://localhost:8290 New task It starts an agent session in tmux at once, and a session costs tokens.
