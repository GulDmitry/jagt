Install

On a desktop

macOS, Linux and WSL:

$ curl -fsSL https://github.com/GulDmitry/jagt/releases/latest/download/install.sh | sh

Windows, in PowerShell:

PS> irm https://github.com/GulDmitry/jagt/releases/latest/download/install.ps1 | iex

Both install for your user only, without admin rights, and check the download against its published checksum.

Run jagt, then open the board at http://localhost:8290.

On a server

Name your project in jagt.server.yml.dist first: the image bakes it in as the starting jagt.yml.

$ docker compose up -d --build

One container with the board behind a password login: docs/server.md.

For engineers

Eight architecture principles, each with the file that holds it: Architecture principles.

1

Roles are isolated folders

What it is
a role is one folder with its brief, its cases and a design file. jagt installs a role. It does not code one.
Why it matters
a new role changes no existing role, and one role can break only itself.
Held by
roles/session/design.md, roles/master/design.md, ARCHITECTURE.md
2

A statechart decides every status

What it is
a capability does its work and reports an outcome. The chart says which status that outcome leads to. Guards read facts.
Why it matters
no code path can move a task to a status the chart does not allow.
Held by
task-flow, 0110, ARCHITECTURE.md
3

A typed protocol

What it is
every message from a session, and every read, is a record checked against a schema once, at the door.
Why it matters
jagt never parses prose, so a changed sentence cannot change a decision.
Held by
protocol, 0077
4

Deterministic beats a model

What it is
triggers, guards and legal moves belong to the machine. A model supplies judgement only.
Why it matters
the Master in act mode picks one legal move and cannot invent one, so an unattended run stays inside the rules.
Held by
master, AGENTS.md
5

Every third party is a configured seam

What it is
one port, one driver for each vendor, and a key in jagt.yml that names the driver.
Why it matters
jagt guesses no vendor from a name or a URL, and swapping a vendor is a config change.
Held by
0130, seams
6

What a session does is read, not asked

What it is
jagt learns what a session does from its CLI's hooks and logs. No model sits in that path.
Why it matters
the state of a session costs no tokens and cannot be a model's guess.
Held by
runtime, 0115
7

Rings, and a test for every rule

What it is
the core imports no Spring, and arrows point inward only. Each rule is a test over all code.
Why it matters
a rule that a test checks does not erode when the code grows.
Held by
ARCHITECTURE.md, 0162, 0180
8

Use cases first

What it is
every behaviour is a WHEN and THEN scenario in a spec, and a test pins it.
Why it matters
a change shows its effect as a scenario before it shows as code.
Held by
spec-changes, testing
