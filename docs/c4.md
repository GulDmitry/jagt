|-----------|-------|---------|

## The hook layers

Three layers stand between a session and the outside, each refusing one thing.

```mermaid
flowchart TB
    call["Session runs a tool"] --> pre{"<b>1 · CLI gate</b><br/>PreToolUse → jagt"}
    pre -- "push to another branch" --> no1["refused, the model reads why"]
    pre -- "allowed" --> perm{"<b>2 · CLI permissions</b><br/>settings.local.json allow-list,<br/>else the auto-mode classifier"}
    perm -- "denied" --> no2["denied"]
    perm -- "git push" --> git{"<b>3 · jagt pre-push</b><br/>.jagt/hooks, git's own"}
    git -- "another branch,<br/>or a delete" --> no3["nothing leaves"]
    git -- "own branch" --> proj["the project's own hooks"] --> remote["origin"]

    ev["Stop · Notification · SessionStart"] -- "CLI hooks" --> rep["/api/agent/session<br/>waiting · idle · gone"]
```

- Layer 3 catches a CLI with no hooks of its own; nothing is ever written into the repository's `.git/hooks`.
- The allow-list is jagt's plus `agentAllowedTools`: a ship's request write is pre-approved, never guessed at.
- Event hooks only report; liveness is read from the CLI's own log, so a session out of tokens still reaches the board.

## The Master

An unattended reader in `judge`; in `act` it also stands where the human stands.

```mermaid
flowchart LR
    subgraph trig["Jobs · the machine's trigger"]
        mr["master-review<br/>a plan or a round handed back"]
        ma["master-answer<br/>a session asks, in act"]
        md["master-deploy<br/>a green request, in act"]
    end
    panel["MasterPanel<br/>brief + plan or round + human's words"]
    roles["headless reads<br/>read-only: no write, commit, push"]
    verd["MasterVerdicts"]

    mr --> panel
    ma --> panel
    panel --> roles -- "verdict, findings" --> verd
    verd -- "not ready · question · answer" --> rel["task_context.md<br/>→ the session"]
    verd -- "ready, in act" --> ship["MasterShip → ship, or start the plan"]
    verd -- "a do line, in act" --> open["TaskLauncher<br/>a task of its own"]
    md --> dep["deploy"]
```

- The model judges, the machine moves: every press goes through `FlowRules` like yours
  ([0006](decisions/0006-the-machine-owns-every-move-a-model-only-judges.md)).
- `master.mine` keeps named steps human; the human's own words in the session overrule any decision
  ([0010](decisions/0010-the-humans-own-word-stands-over-the-master.md)).
